# TalosDeck — подготовка к релизу

Обновлено: 12 сентября 2026. Проверена ветка `redesign/operator-console`, код `dfd4a52`.

## Оценка готовности

**Проект подходит для дальнейшего лабораторного тестирования, но пока не готов к полноценному production-релизу.** Основные функции реализованы, новый интерфейс собирается и проходит браузерный smoke-тест. Однако наличие функций не подтверждает безопасность удаления воркеров, восстановление из резервной копии и надёжность эксплуатации.

В [BUGS.md](BUGS.md) числятся **26 открытых дефектов: 7 High, 11 Medium, 8 Low**. Это состояние трекера, а не результат повторного воспроизведения всех 26 ошибок. Часть записей относится к старому интерфейсу и требует пересмотра. В текущем коде подтверждены продолжение запуска при отказе аудита и игнорирование ошибок записи журнала.

Прежняя дорожная карта с пятью «завершёнными» фазами заменена этим списком: она описывала старый UI и ошибочно приравнивала реализацию к готовности к production. История сохранена в Git; история интерфейса — в [FRONTEND_REBUILD.md](FRONTEND_REBUILD.md) и [FRONTEND_REDESIGN_TODO.md](FRONTEND_REDESIGN_TODO.md).

## Блокеры релиза

Все задачи ниже открыты. Приоритет определяет порядок работ; исходная severity дефектов остаётся в BUGS.md. Закрывать строку только с ссылкой на исправление и результат проверки.

| ID | Приоритет | Задача | Критерий готовности |
|---|---|---|---|
| REL-01 | P0 | Исправить удаление воркеров: PVE-18, PVE-19, PVE-20 | Отсутствующий Kubernetes Node не блокирует очистку ВМ; после удаления нет зомби-объекта; таймаут ACPI и блокировки Proxmox корректно обработаны. Повтор операции безопасен. Есть регрессионные тесты и прогон на стенде |
| REL-02 | P0 | Обеспечить надёжность аудита: SEC-19, SEC-20 | Ошибка открытия/записи журнала видна оператору; чувствительные операции не продолжаются молча без обязательного аудита. Проверены недоступный каталог, read-only filesystem и заполненный диск |
| REL-03 | P0 | Исправить скачивание и очистку бэкапов: BKP-18, BKP-19 | Большой архив скачивается без накопления всего файла в памяти вкладки; осиротевшие sidecar-файлы удаляются по корректному ID. Есть проверки целостности скачанного архива и регрессий |
| REL-04 | P0 | Доказать восстановление из резервной копии | На отдельном кластере выполнено восстановление по инструкции из полного архива и etcd snapshot; проверены данные и работоспособность workloads. Зафиксированы версии, ограничения, время восстановления и место внешнего хранения копии. Автоматизация restore в UI не обязательна |
| REL-05 | P0 | Подготовить безопасную установку | Deployment получает пароль и JWT secret через Secret; инструкция не предлагает пароль `admin` (код генерирует временный пароль при отсутствии настройки). Описаны HTTPS/WSS, доступ к панели и права на talosconfig/архивы; проверены неавторизованные запросы к чувствительным API |
| REL-06 | P0 | Добавить воспроизводимую CI-проверку релиза | В репозитории нет `.gitlab-ci.yml` и `.github/workflows`. Pipeline на чистом runner выполняет Go tests/vet/race, frontend build/smoke и сборку/запуск Docker. Ошибка frozen lockfile останавливает сборку: убрать `bun install --frozen-lockfile || bun install`. Браузер устанавливается в CI, путь не зависит от `/usr/bin/chromium` разработчика |

## Условия выпуска

- [ ] Закрыты REL-01–REL-06; открытых подтверждённых High/Critical нет.
- [ ] Выполнены REL-07–REL-16 либо для исключений зафиксированы причина, ограничения и решение о переносе. Риски потери данных и обхода защиты не переносятся ради даты релиза.
- [ ] На выделенном стенде успешно пройдены установка, ключевые операции, восстановление, обновление и откат.
- [ ] CI прошёл на точном коммите релизного тега; протестирован именно публикуемый образ.
- [ ] Ветка нового интерфейса прошла итоговое ревью и включена в релиз; документация соответствует поставке.

Рекомендуемый порядок: **аудит и удаление воркеров → резервные копии и восстановление → безопасная поставка/CI → оставшиеся дефекты и стенд → документация и RC**. Процент готовности не приводится: прохождение сборки не измеряет надёжность восстановления и эксплуатации.
