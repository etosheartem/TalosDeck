# Шаблоны кластеров

Шаблон фиксирует версии Talos/Kubernetes, schematic Image Factory, CNI/storage add-on, количество control-plane/worker нод и ресурсы VM. Поддерживаются 1 или 3 control-plane ноды, суммарно до 100 машин, metal/amd64.

Каждое изменение создаёт новую immutable revision с автором, датой и SHA256 типизированного JSON spec. Hash обнаруживает изменение спецификации, но не является цифровой подписью. Provisioning plan использует снимок выбранной ревизии; редактирование шаблона не меняет уже запланированные операции.

В шаблоне нет credentials, произвольного YAML, MachineConfig, IP-адресов машин или токенов. Provider, имя нового кластера, endpoint, ISO storage и имена/адреса машин выбираются при создании плана. Переопределять закреплённые версии, schematic или ресурсы через параметры запуска нельзя — создайте новую ревизию.

Статический network mode разрешён в defaults; адрес, gateway и nameservers задаются отдельно при запуске. Количество и роли машин должны точно совпадать с ревизией. Версии и ресурсы проверяет валидатор обычного provisioning. Свежая проверка Factory, qemu-guest-agent и provider выполняется при создании/исполнении плана.

Архивация скрывает шаблон и запрещает новые планы через API. Ревизии сохраняются для истории. Изменения используют `expectedRevision`: если другой администратор создал новую ревизию, перечитайте состояние после conflict.

Registry — encrypted aggregate в fleet scope SQLite. Один mutex и одна запись обеспечивают атомарность в standalone процессе; несколько активных реплик не поддерживаются. Лимиты: 100 шаблонов, 100 ревизий каждого, aggregate до 8 MiB. При достижении лимита новая запись отклоняется без удаления истории.
