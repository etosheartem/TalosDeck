# Health Score

Health Score — объяснимая оценка наблюдаемых условий, а не SLA, вероятность аварии или аудит безопасности. Диагностика и оценка используют один snapshot; `snapshotId` связывает число с исходными проверками. Отправка, повтор, подтверждение и отключение уведомлений на оценку не влияют.

## Политика v1

| Категория | Вес |
|---|---:|
| Control plane | 15 |
| Etcd | 20 |
| Nodes | 15 |
| Storage | 15 |
| Networking | 10 |
| Workloads | 10 |
| Backups | 10 |
| Certificates | 5 |

В каждой категории применяется только худший известный результат: healthy — без штрафа, warning — 25 пунктов, critical — 75. Для critical с причинами `quorum-lost`, `certificate-expired`, `not-yet-valid` штраф равен 100. Категория получает `100 − штраф`; общий score — сумма оценок категорий, умноженных на их веса и делённых на 100. Штраф ссылается на конкретный `checkId`; при равных штрафах выбирается первый ID в сортировке. Другие проблемы остаются в findings, но не умножают штраф.

Состояния и причины задаёт collector. Например, короткоживущий автоматически ротируемый Talos server certificate, признанный collector здоровым, не штрафуется повторно общими порогами сертификатов. Категория Certificates не оценивает уязвимости, RBAC или всю PKI кластера.

## Неполные и устаревшие данные

Проверка считается актуальной не дольше десяти минут. Истёкший срок snapshot делает все его проверки неизвестными; устаревшая отдельная проверка снижает покрытие своей категории. Время из будущего и отсутствующий timestamp также не считаются актуальными.

Coverage категории — доля известных проверок среди ожидаемых записей её snapshot. Collector обязан добавлять unknown при неполном источнике/инвентаризации; отсутствие findings само по себе не подтверждает покрытие. Полностью отсутствующая категория получает synthetic unknown. Общий coverage — взвешенная сумма покрытия категорий.

Если в категории есть unknown, её `score=null`. Если хотя бы одна обязательная категория неполна, общий `score=null`. `observedScore` отдельно показывает результат только по доступной части, вместе с coverage и временем: его нельзя показывать как обычное зелёное «100». Его веса пропорциональны покрытию категорий. Известный critical сохраняет критический статус даже при неполных данных; затем по приоритету warning, unknown, healthy.

`not-applicable` допустим только как явное подтверждение collector, что проверка неприменима. Он учитывается как известный результат без штрафа. Отсутствующая проверка, ошибка доступа и отключённый источник не заменяются на not-applicable.

Повторные ID внутри категории дедуплицируются детерминированно, без суммирования штрафов; выбирается более серьёзное состояние. Evaluator не меняет snapshot, не обращается к API и не выполняет инфраструктурных операций.

## Работа с оценкой

Откройте **Наблюдение → Здоровье**. Выбор категории раскрывает проверки и
вычет; Check ID связывает его с находкой и переходом к ноде или логам.
Краткая оценка с покрытием также доступна в обзоре кластера.

`GET /api/clusters/:id/health-score` доступен всем ролям и читает сохранённый
снимок. Он не создаёт задания и не опрашивает инфраструктуру при каждом открытии
страницы. Фоновая проверка выполняется каждые пять минут с общим лимитом 45 секунд.
**Диагностика → Проверить кластер** обновляет этот же источник; сохранённый отчёт
содержит оценку своего `snapshotId`. После следующего фонового опроса более новая
оценка может иметь другой ID. Дополнительные недавние Kubernetes events в
диагностике не штрафуют score повторно.

Снимки хранятся зашифрованными отдельно для каждого кластера. После перезапуска
сохраняется исходное время наблюдения; старый снимок не становится свежим только
из-за перезапуска. При ошибке сохранения API сообщает недоступность оценки.

Неполученные данные диска остаются unknown, даже если отображаемый процент равен
нулю. Проверка CNI использует конфигурацию Talos и распознанные DaemonSet образы,
а не все workloads пространства kube-system. Накопленное число перезапусков pod
не считается новым отказом. Проверка бэкапов оценивает наличие полной копии за
24 часа; результат не утверждает, что восстановление этой копии было испытано.
